# 人身意外险保险条款（2023版）

适用期间：2023年1月1日 至 2023年12月31日

## 一、保障范围

### 1.1 身故保障
被保险人因意外事故导致身故，保险公司给付身故保险金，保险金额为 **50万元**。

### 1.2 伤残保障
被保险人因意外事故导致伤残，按伤残等级给付伤残保险金：
- 一级伤残：赔付保额的 100%
- 二级伤残：赔付保额的 90%
- 三级伤残：赔付保额的 80%
- 四级至十级：依等级比例递减

### 1.3 医疗费用报销
因意外事故产生的住院医疗费，报销上限为 **10万元**，免赔额 **500元**。

## 二、责任免除

以下情况不在保障范围内：
- 被保险人故意自伤或自杀
- 酒后驾车或无证驾车
- 参与违法犯罪活动
- 战争、武装冲突
- 核辐射或核污染

## 三、等待期

本保单无等待期，自保险合同生效之日起即刻保障。

## 四、保费与缴费

| 年龄段 | 年缴保费 |
|--------|---------|
| 18-30岁 | 388元 |
| 31-40岁 | 488元 |
| 41-50岁 | 688元 |
| 51-60岁 | 988元 |

## 五、理赔流程

1. 事故发生后 **30天内** 通知保险公司
2. 提交理赔申请及相关证明材料
3. 保险公司 **5个工作日内** 完成核定
4. 核定通过后 **10个工作日内** 完成赔付
