# 人身意外险保险条款（2026版）

适用期间：2026年1月1日 至 2026年12月31日

## 一、保障范围

### 1.1 身故保障
被保险人因意外事故导致身故，保险公司给付身故保险金，保险金额为 **200万元**（较2025版提升33%）。

### 1.2 伤残保障
被保险人因意外事故导致伤残，按伤残等级给付伤残保险金（等级赔付比例与2025版一致，不变）。

### 1.3 医疗费用报销
因意外事故产生的住院医疗费，报销上限提升至 **50万元**，无免赔额，**新增境外就医报销**，境外上限为国内上限的50%（25万元）。

### 1.4 住院津贴
被保险人因意外住院，每日给付住院津贴调整为：
- 普通病房：**400元/天**（较2025版提升100元）
- ICU病房：**800元/天**（2026年新增ICU加倍条款）
- 最长不超过365天

### 1.5 意外门诊
意外事故发生后 **96小时内**（较2025版延长24小时）就诊的门诊费用，报销上限提升至 **15000元**，无免赔额。

### 1.6 意外骨折专项保障
因意外导致骨折，额外给付骨折理赔金 **8000元**（较2025版提升3000元），无需住院即可申请。

### 1.7 救护车费用保障
因意外事故使用救护车转运，报销救护车费用上限提升至 **5000元**（较2025版提升3000元）。

### 1.8 新增：心理援助保障（2026年新增）
因意外事故导致心理创伤，提供最多 **10次** 心理咨询服务，每次上限 **500元**。

### 1.9 新增：家庭护理补贴（2026年新增）
因严重意外导致一级或二级伤残，每月给付家庭护理补贴 **2000元**，最长 **24个月**。

## 二、责任免除

以下情况不在保障范围内：
- 被保险人故意自伤或自杀
- 酒后驾车或无证驾车
- 参与违法犯罪活动
- 战争、武装冲突
- 核辐射或核污染
- 职业运动员参与专业竞技活动
- **新增：飞行器驾驶员执行商业飞行任务**（专业航空人员需另购航空险）

## 三、等待期

本保单无等待期，自保险合同生效之日起即刻保障。

## 四、保费与缴费

| 年龄段 | 年缴保费 |
|--------|---------|
| 18-30岁 | 1088元 |
| 31-40岁 | 1488元 |
| 41-50岁 | 2188元 |
| 51-60岁 | 3188元 |
| 61-65岁 | 4588元 |

> 注：2026版因新增境外医疗、ICU加倍、心理援助、家庭护理等条款，保费较2025版上调约35%。

## 五、理赔流程

1. 事故发生后 **60天内** 通知保险公司（较2025版宽限期延长一倍，更宽容）
2. 提交理赔申请及相关证明材料（支持电子材料，无需原件）
3. 保险公司审核时限维持 **2个工作日**
4. 核定通过后 **3个工作日内** 完成赔付（较2025版再提速）
5. 支持线上一键理赔、微信小程序入口
6. **新增：理赔进度实时推送**，短信 + APP 双通知
7. **新增：争议调解绿色通道**，30天内未解决可申请第三方调解

## 六、特别约定（2026年新增）

- 被保险人可指定最多 **3名** 受益人（2025版仅支持1名）
- 保单有效期内可免费更换受益人 **2次**
- 支持 **家庭打包投保**，同一家庭3人以上投保，保费八折优惠
