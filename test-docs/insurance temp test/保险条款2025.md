# 人身意外险保险条款（2025版）

适用期间：2025年1月1日 至 2025年12月31日

## 一、保障范围

### 1.1 身故保障
被保险人因意外事故导致身故，保险公司给付身故保险金，保险金额为 **150万元**（较2024版提升50%）。

### 1.2 伤残保障
被保险人因意外事故导致伤残，按伤残等级给付伤残保险金：
- 一级伤残：赔付保额的 100%
- 二级伤残：赔付保额的 90%
- 三级伤残：赔付保额的 80%
- 四级至十级：依等级比例递减
- **新增：轻度伤残（十一至十四级）赔付保额 10%-30%**

### 1.3 医疗费用报销
因意外事故产生的住院医疗费，报销上限提升至 **30万元**，**取消免赔额**（2024版免赔额200元）。

### 1.4 住院津贴
被保险人因意外住院，每日给付住院津贴 **300元**（较2024版提升50%），最长不超过365天（较2024版延长185天）。

### 1.5 意外门诊
意外事故发生后 **72小时内** 就诊的门诊费用，报销上限提升至 **10000元**（较2024版翻倍），无免赔额。

### 1.6 新增：意外骨折专项保障（2025年新增）
因意外导致骨折，额外给付骨折理赔金 **5000元**，无需住院即可申请。

### 1.7 新增：救护车费用保障（2025年新增）
因意外事故使用救护车转运，报销救护车费用上限 **2000元**。

## 二、责任免除

以下情况不在保障范围内：
- 被保险人故意自伤或自杀
- 酒后驾车或无证驾车
- 参与违法犯罪活动
- 战争、武装冲突
- 核辐射或核污染
- 职业运动员参与专业竞技活动
- **删除原有：高空作业免责条款**（2025年起高空作业纳入保障）

## 三、等待期

本保单无等待期，自保险合同生效之日起即刻保障。

## 四、保费与缴费

| 年龄段 | 年缴保费 |
|--------|---------|
| 18-30岁 | 798元 |
| 31-40岁 | 1088元 |
| 41-50岁 | 1588元 |
| 51-60岁 | 2288元 |
| **新增 61-65岁** | **3288元** |

> 注：2025版新增61-65岁投保选项，保障范围同步扩大至老龄群体。

## 五、理赔流程

1. 事故发生后 **30天内** 通知保险公司
2. 提交理赔申请及相关证明材料
3. 保险公司审核时限缩短至 **2个工作日**（较2024版再提速）
4. 核定通过后 **5个工作日内** 完成赔付（较2024版缩短5天）
5. 支持线上一键理赔，无需到访柜台
6. **新增：微信小程序申请入口**，全程无纸化理赔
