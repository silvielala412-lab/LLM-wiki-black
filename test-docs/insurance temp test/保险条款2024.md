# 人身意外险保险条款（2024版）

适用期间：2024年1月1日 至 2024年12月31日

## 一、保障范围

### 1.1 身故保障
被保险人因意外事故导致身故，保险公司给付身故保险金，保险金额为 **100万元**（较2023版提升100%）。

### 1.2 伤残保障
被保险人因意外事故导致伤残，按伤残等级给付伤残保险金：
- 一级伤残：赔付保额的 100%
- 二级伤残：赔付保额的 90%
- 三级伤残：赔付保额的 80%
- 四级至十级：依等级比例递减

### 1.3 医疗费用报销
因意外事故产生的住院医疗费，报销上限提升至 **20万元**，免赔额降低至 **200元**。

### 1.4 新增：住院津贴（2024年新增条款）
被保险人因意外住院，每日给付住院津贴 **200元**，最长不超过180天。

### 1.5 新增：意外门诊（2024年新增条款）
意外事故发生后 **72小时内** 就诊的门诊费用，报销上限为 **5000元**，无免赔额。

## 二、责任免除

以下情况不在保障范围内：
- 被保险人故意自伤或自杀
- 酒后驾车或无证驾车
- 参与违法犯罪活动
- 战争、武装冲突
- 核辐射或核污染
- **新增：职业运动员参与专业竞技活动**（2024年新增免责项）

## 三、等待期

本保单无等待期，自保险合同生效之日起即刻保障。

## 四、保费与缴费

| 年龄段 | 年缴保费 |
|--------|---------|
| 18-30岁 | 598元 |
| 31-40岁 | 798元 |
| 41-50岁 | 1088元 |
| 51-60岁 | 1588元 |

> 注：因保障范围扩大，2024版保费较2023版上调约55%。

## 五、理赔流程

1. 事故发生后 **30天内** 通知保险公司
2. 提交理赔申请及相关证明材料
3. 保险公司审核时限由 **5个工作日** 缩短至 **3个工作日**
4. 核定通过后 **10个工作日内** 完成赔付
5. **新增：支持线上一键理赔**，无需到访柜台
