# Python 数据类型详解

Python 内置了多种数据类型，理解它们是编写正确程序的基础。

## 基本类型

| 类型 | 示例 | 说明 |
|------|------|------|
| int | 42 | 整数，无大小限制 |
| float | 3.14 | 浮点数 |
| str | "hello" | 字符串，不可变 |
| bool | True | 布尔值 |

## 容器类型

- **list**：有序可变序列，`[1, 2, 3]`
- **tuple**：有序不可变序列，`(1, 2, 3)`
- **dict**：键值对映射，`{"key": "value"}`
- **set**：无序不重复集合，`{1, 2, 3}`

## 类型检查

使用 `type()` 或 `isinstance()` 进行类型检查。
