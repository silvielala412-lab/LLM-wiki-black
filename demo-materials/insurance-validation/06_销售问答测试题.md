# 销售问答测试题

> Mock 数据，用于上传前 5 份材料后验证问答效果。

## 产品理解类

1. 安心家庭守护重疾险的等待期是多少？
2. 这个产品有哪些服务权益？
3. 家庭医生服务能不能代替线下诊疗？
4. 这个产品不适合哪些客户？

## 客户画像类

1. 这个产品适合什么样的客户？
2. 35 岁家庭经济支柱通常有哪些购买信号？
3. 高净值家庭健康管理客户最关心什么？
4. 客户说“我不缺这点赔付”时，可能属于哪个画像？

## 销售方法类

1. 客户说“我已经有医保了”，应该怎么回应？
2. 客户说“保费太贵”，应该怎么回应？
3. 最近体检异常的客户，适合用什么销售场景？
4. 有房贷和孩子教育支出的客户，应该怎么切入？

## 关系验证类

1. 家庭医生服务应该关联到哪些客户画像？
2. 重疾绿通服务应该关联到哪些销售话术？
3. 家庭经济支柱画像应该关联到哪些产品卖点？
4. “医保够不够”这个异议应该关联到哪个产品责任？

## 缺口验证类

1. 当前材料缺少哪些产品信息？
2. 当前材料缺少哪些客户画像？
3. 当前材料缺少哪些销售方法？
4. 哪些宣传表达需要合规审核？
