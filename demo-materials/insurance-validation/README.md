# Insurance Validation Mock Materials

这些文件用于验证 LLM Wiki 的第一版保险销售知识 demo：

- Product 产品域：产品条款、产品说明书、宣传素材
- Customer 客户画像域：家庭经济支柱、高净值健康管理客户
- Method 销售方法域：销售场景、话术、异议处理、转介绍

建议上传顺序：

1. `01_产品条款_安心家庭守护重疾险.md`
2. `02_产品说明书_安心家庭守护重疾险.md`
3. `03_产品宣传素材_家庭健康守护海报文案.md`
4. `04_客户画像_家庭经济支柱与健康焦虑客户.md`
5. `05_销售方法_安心家庭守护销售打法.md`

上传后再用 `06_销售问答测试题.md` 里的问题验证问答效果。

预期能验证的能力：

1. 编译结果：是否生成 Product / Customer / Method 三类知识页。
2. 知识关联：产品卖点是否能关联客户画像和销售方法。
3. 缺口补全：是否提示费率表、轻症清单、旧保单加保话术、合规规则等缺口。
4. 问答使用：是否能回答产品、客户、销售话术和合规风险类问题。
